# Evaluation

## Purpose

Use this file for critique passes after the first implementation. The goal is to catch generic, incoherent, or impractical design decisions before stopping.

## Fast Rubric

Score each area mentally as strong, weak, or unresolved.

- Originality: Does the page feel authored or like a default template with nicer colors?
- Coherence: Do palette, type, shape, imagery, and motion belong to the same world?
- Hierarchy: Is the reading order obvious within two seconds?
- Functionality: Can users still navigate, scan, and act without friction?
- Responsiveness: Does the idea survive on mobile?
- Accessibility: Are contrast, focus, and motion constraints respected?

## Symptoms Of Generic Work

- The hero is attractive, but every downstream section returns to standard SaaS cards.
- Visual style depends mostly on a gradient background.
- Typography has no role contrast.
- Accent color appears everywhere, so nothing feels important.
- Decorative elements could be removed without changing the page's identity because they were never integrated.

## Refinement Order

Fix in this order:

1. Concept coherence
2. Hierarchy and readability
3. Component consistency
4. Mobile translation
5. Motion and polish

Do not spend the final hour polishing shadows on a layout whose concept is still weak.

## Revision Prompts

Ask:

- What is the single strongest visual idea here?
- Where does the design quietly become generic again?
- Which component looks imported from another aesthetic system?
- Which section is overdesigned relative to its importance?
- Which choice improves atmosphere but harms clarity?
- What could be removed with no loss? Cut it.

## Final Check

Before stopping, verify:

- The UI has one memorable move and one stable system.
- Interactive states remain legible.
- Type sizes and spacing are consistent with the intended tone.
- The design would still feel distinct in grayscale.
- The layout tells the same story on mobile, even if the composition changes.
