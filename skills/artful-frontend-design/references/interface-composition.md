# Interface Composition

## Purpose

Use this file when shaping layout, components, and interaction rhythm so the interface feels authored without sacrificing usability.

## One Memorable Move

Give the page one instantly legible signature move.

Examples:

- A hero framed like a magazine spread
- Oversized navigation with tiny supporting metadata
- A dense data panel floating inside a soft atmospheric field
- Alternating section widths that create a procession
- A staggered image wall with strict text rails
- Strong left-hand index/navigation that persists through the page

One memorable move is enough. More than that often becomes noise.

## Composition Principles

- Let the grid support the concept rather than flatten it.
- Use asymmetry deliberately; keep alignment anchors visible.
- Create areas of rest so high-drama sections feel intentional.
- Vary information density by section.
- Treat whitespace as structure, not leftover space.

## Hero Design

The hero should communicate concept, hierarchy, and motion potential immediately.

Consider:

- Can the headline shape contribute to the composition?
- Should supporting copy be quiet and narrow instead of centered and wide?
- Can metadata, badges, or stats create tension around the main headline?
- Should the primary action feel integrated into the composition rather than bolted underneath?

## Navigation

Navigation must stay clearer than the surrounding styling.

- Keep labels short and literal.
- Use contrast, weight, or framing to distinguish navigation from ornament.
- If the design is visually dense, simplify nav behavior.
- If the design is visually minimal, nav can carry more personality through type and spacing.

## Sections And Cards

Do not repeat the same card treatment for every block on the page.

Vary by content role:

- Feature explanation: calm and readable
- Social proof: compressed and rhythmic
- Metrics: high contrast and grid-driven
- Storytelling: image-led or sequential
- CTA: heightened but not disconnected from the palette

Cards should inherit a family resemblance through radius, border logic, or typography, not clone one another exactly.

## Forms And Product UI

Highly styled UI still needs operational clarity.

- Keep input affordances obvious.
- Use restrained backgrounds behind dense form controls.
- Let labels and helper text stay visually subordinate but readable.
- Save unusual treatments for shells, grouping, and transitions rather than the text fields themselves.

## Motion

Motion should reinforce hierarchy and spatial logic.

Useful motion patterns:

- Staggered section reveals
- Mask/unmask for headlines or imagery
- Parallax with strict limits
- Panel slides that clarify state changes
- Hover changes that reveal texture, light, or depth

Avoid:

- Constant floating animation
- Large delays on core actions
- Motion that changes layout unexpectedly
- Decorative animation with no narrative or feedback value

## Responsive Translation

Keep the main concept intact across breakpoints.

- Decide what the signature move becomes on mobile before implementation.
- Collapse asymmetry into stacked rhythm, not visual mush.
- Preserve strong type contrast even when scale is reduced.
- Rebuild section spacing for touch instead of merely shrinking desktop gaps.
- Reassess sticky elements and large layered backgrounds on small screens.
